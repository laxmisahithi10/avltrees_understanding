# Balanced Binary Search Trees

This repository explains Balanced Binary Search Trees, with a focus on
AVL Trees and Red-Black Trees.

It contains both theoretical explanations and a web-based BST/AVL
visualizer project.

## Contents

### Theory

1. [Need for Balanced BST]
   - Why normal BSTs can become inefficient
   - Best, average and worst-case complexity
   - Search, insertion, deletion and minimum operations

2. [Types of Balanced Trees]
   - AVL Trees
   - Red-Black Trees
   - B-Trees
   - B+ Trees

3. [AVL Tree Imbalance]
   - Balance Factor
   - LL imbalance
   - RR imbalance
   - LR imbalance
   - RL imbalance

4. [AVL Rotations]
   - LL Rotation
   - RR Rotation
   - LR Rotation
   - RL Rotation

5. [AVL vs Red-Black Trees]
   - Comparison
   - Use cases
   - Why Java uses Red-Black Trees
   - TreeMap and HashMap

### Project

6. [Web-Based BST/AVL Visualizer]

The visualizer demonstrates tree insertion, deletion, balancing and
rotations interactively.

## Technologies

- HTML
- CSS
- JavaScript
- Data Structures and Algorithms

## Learning Objectives

- Understand why ordinary BSTs can become inefficient
- Understand balanced search trees
- Learn AVL tree balancing and rotations
- Compare AVL and Red-Black trees
- Visualize tree operations using a web application
